## Practice Quizzes & Conceptual MCQs

### 1. [Application] What is the state of a process when it is in the 'running' instance?

- **A.** Terminated
- **B.** New
- **C.** Ready Running
- **D.** Waiting Block

- **Answer:** C (Ready Running)
- **Explanation:** A running instance refers to an application's executable file that has been loaded into memory and is currently being executed. Therefore, the state of a process when it is in the 'running' instance is 'ready running'. The other options are incorrect because they describe different states: 'new' means the process was just created but not yet started; 'waiting block' indicates the process is waiting for some condition to be met before proceeding; and 'terminated' signifies that the process has ended.
- **Concept:** Running Instance

### 2. [Conceptual] What does a process state of 'new' indicate?

- **A.** The process has terminated
- **B.** The process is in the middle of execution
- **C.** The process is waiting for resources
- **D.** The process has been created but not yet started

- **Answer:** D (The process has been created but not yet started)
- **Explanation:** A 'new' state indicates that a process has just been created and has not yet begun executing. It signifies that the system is allocating resources for this new process, which will start running when it is scheduled by the scheduler.
- **Concept:** \<concept\>

### 3. [Application] What is the state of a process when it is waiting for I/O to complete?

- **A.** Blocked
- **B.** Ready
- **C.** Terminated
- **D.** Running

- **Answer:** A (Blocked)
- **Explanation:** A process that is blocked means it has been temporarily halted due to an external event, such as waiting for I/O completion. In the context of a system with multiple processes, this could be one of several states: new, ready, running, or terminated.
- **Concept:** Turnaround Time

### 4. [Application] What is the state of a process when it has been newly created and not yet started executing?

- **A.** Ready to run
- **B.** Waiting for resources
- **C.** Terminated
- **D.** New

- **Answer:** D (New)
- **Explanation:** The correct answer is 'New'. A process that has just been created but has not yet started executing is in the new state. This means it is ready to be scheduled by the operating system for execution.
- **Concept:** \<concept\>

### 5. [Application] What is the state of a process after it has been created?

- **A.** Ready
- **B.** New
- **C.** Running
- **D.** Terminated

- **Answer:** B (New)
- **Explanation:** The correct answer 'New' indicates that the process has just been initiated and is ready to start execution. The other options are incorrect because a newly created process cannot be running, terminated, or in any of the waiting states without further instructions.
- **Concept:** Operating System
